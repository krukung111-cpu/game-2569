# Career Quest — โลกของอาชีพ

**แนวทางล่าสุด: Firebase Spark ฟรี + GitHub** ดู [FIREBASE.md](FIREBASE.md) สำหรับการตั้งค่า Auth, Firestore, Hosting และสิทธิ์ครู โดยไม่ใช้ Cloud Functions คำสั่ง `npm start` ด้านล่างเป็นโหมดเซิร์ฟเวอร์เดิมสำหรับพัฒนาในเครื่อง

เกมผจญภัยการศึกษาวิชาการงานอาชีพ ชั้น ม.1
ครูธวัฒน์ สารรัตน์ · โรงเรียนศรีเจริญศึกษา

## เริ่มใช้งาน
ใช้ Node.js 18 ขึ้นไป ไม่ต้องติดตั้ง dependencies

```sh
npm start
```
พอร์ตเริ่มต้น 3000 เปลี่ยนได้ด้วย `PORT` นักเรียนทุกเครื่องต้องเข้าเซิร์ฟเวอร์เดียวกันผ่านเบราว์เซอร์ จึงจะมีอันดับและข้อมูลครูร่วมกัน เปิดไฟล์ HTML โดยตรงจะใช้ระบบบันทึกผลไม่ได้

## นักเรียน
ลงทะเบียนชื่อ–สกุล ชั้นรูปแบบ ม.1/1 และเลขที่ 1–99 ชั้น+เลขที่ห้ามซ้ำ มี 5 ด่าน ด่านละ 3 คำถาม ตอบถูกได้ 100 คะแนนและ 1 ดาว มีคำอธิบายทั้งเมื่อตอบถูกและผิด จบด่านจึงปลดล็อกด่านถัดไป เล่นซ้ำได้ เก็บสถิติที่ดีที่สุด สูงสุด 1,500 คะแนน/15 ดาว คะแนนเสมอกันได้อันดับร่วมกัน กระดานสาธารณะแสดงเฉพาะชื่อแรกและชั้น

เซิร์ฟเวอร์ตรวจคำตอบและคำนวณคะแนน ไม่รับคะแนนจากหน้าจอโดยตรง แต่เป็นเกมฝึกเรียนรู้ที่แสดงเฉลย ไม่ใช่ระบบสอบที่ป้องกันการทุจริต ข้อมูลตัวตนนักเรียนเป็น token ใน localStorage ของเบราว์เซอร์ ใช้อุปกรณ์เดิมเพื่อเล่นต่อ การออกจากบัญชีหรือล้างข้อมูลจะทำให้ต้องติดต่อผู้ดูแลเพื่อกู้การเข้าถึง ไม่ควรลงทะเบียนซ้ำ ให้ใช้โปรไฟล์เบราว์เซอร์แยกสำหรับเครื่องที่ใช้ร่วมกัน

เสียงสังเคราะห์ผ่าน Web Audio เปิด/ปิดด้วยปุ่มเสียง ไม่มีไฟล์เสียงภายนอก ภาพเคลื่อนไหวเคารพการตั้งค่า reduced motion ของอุปกรณ์

## แดชบอร์ดครู
ตั้งตัวแปร `TEACHER_PASSWORD` เป็นรหัสที่โรงเรียนกำหนดก่อนเริ่มเซิร์ฟเวอร์ หากไม่ตั้ง ระบบสร้างรหัสสุ่มใน `.data/teacher-key` (สิทธิ์อ่านเขียนเฉพาะเจ้าของ) ผู้ดูแลเซิร์ฟเวอร์อ่านรหัสนี้แล้วส่งให้ครูเป็นการส่วนตัว อย่านำรหัสหรือไฟล์นี้ขึ้น Git

ปุ่ม “สำหรับครู” เปิดหน้ารหัส ครูดูชื่อเต็ม ชั้น เลขที่ คะแนนแต่ละด่าน คะแนนรวม ดาว จำนวนด่านสำเร็จ กรองตามห้อง และส่งออก CSV ภาษาไทยได้ ปิดหน้าครูแล้วจะล้างข้อมูลและรหัสออกจากหน่วยความจำหน้าจอ

## ข้อมูลและการใช้งานจริง
ข้อมูลเก็บบนเซิร์ฟเวอร์ใน `.data/students.json` (ไม่เข้า Git) ตั้ง `DATA_DIR` เพื่อใช้ตำแหน่งอื่นได้ ต้องสำรองไดเรกทอรีนี้และใช้ดิสก์ถาวร รันเพียงหนึ่งโปรเซสเซิร์ฟเวอร์ต่อไดเรกทอรีข้อมูล เหมาะกับต้นแบบระดับห้องเรียน ยังไม่มีระบบกู้บัญชีด้วยตนเองหรือฐานข้อมูลสำหรับหลายอินสแตนซ์ ผู้ดูแลต้องจัดการข้อมูลและการกู้บัญชีผ่านเซิร์ฟเวอร์

ก่อนใช้จริงกับนักเรียนต้องโฮสต์ด้วย HTTPS และจำกัดผู้เข้าถึงตามนโยบายโรงเรียน การรันใน workspace ยังไม่ได้เผยแพร่เป็นเว็บไซต์สาธารณะ แบบอักษร Google Fonts เป็นส่วนเสริม ออฟไลน์ใช้ฟอนต์บนเครื่องแทน ไม่มี API key หรือบริการภายนอกที่จำเป็นต่อเกม

## ทดสอบ
`npm test` ทดสอบโครงสร้างเนื้อหาและ API ผ่านเซิร์ฟเวอร์ชั่วคราว โดยไม่แตะข้อมูลจริง การทดสอบเบราว์เซอร์ระหว่างพัฒนาได้ตรวจครบ 15 คำถาม การบันทึก อันดับร่วม แดชบอร์ด/CSV และขนาดจอมือถือ ครูควรทบทวนเนื้อหาให้ตรงแผนการสอนก่อนนำไปใช้

## เผยแพร่เว็บไซต์ด้วยแผนฟรี
ดู [FIREBASE.md](FIREBASE.md) สำหรับ Firebase Spark + GitHub ไม่ใช้ Cloud Functions ไม่ต้องผูกบัตรเมื่ออยู่ใน Spark และใช้ภายในโควตา การคำนวณคะแนนในเบราว์เซอร์ป้องกันการโกงได้จำกัด เหมาะกับการฝึกเรียนรู้ ไฟล์เผยแพร่คือ firebase.json, firestore.rules และ public ที่สร้างด้วย scripts/build-firebase.cjs
